StreakMind

Aplicação desktop para acompanhamento de estudos, metas diárias e streak.

Sobre o projeto

O StreakMind é uma aplicação desktop desenvolvida em Python com Tkinter. O objetivo do sistema é ajudar estudantes a manterem consistência nos estudos, registrando sessões, calculando tempo estudado no dia e acompanhando uma streak baseada em metas diárias.

Funcionalidades

  • Dashboard com resumo do dia
  • Registro de sessões de estudo
  • Criação e remoção de tarefas
  • Controle de meta diária
  • Configuração de dias obrigatórios
  • Sistema de streak
  • Persistência de dados em JSON
  • Consulta de feriados nacionais usando API pública
  • Configuração para exigir ou não estudo em feriados

Integração com API pública

O projeto utiliza a BrasilAPI para consultar feriados nacionais. Essa informação é usada para adaptar a lógica da streak, permitindo que o usuário escolha se feriados devem ou não contar como dias obrigatórios de estudo.

Endpoint utilizado: https://brasilapi.com.br/api/feriados/v1/{ano}

Como executar

Clone o repositório, crie o ambiente virtual e instale as dependências:

python -m venv venv
venv\Scripts\activate
python -m pip install -r requirements.txt
python src/main.py
